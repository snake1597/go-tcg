# 12.5: 建立統一 Ability 與 Effect Runtime

**What to build:** 建立固定 Support Set 可共用的 activated／triggered ability 執行核心：以 Ability Instance、typed operation、統一 Effects Stack item、可重播 Pending Choice 與 continuous effect lifecycle 處理能力的宣告、付款、結算與事件。

**Blocked by:** 10: 以 Impact Hammer 完成觸發收集與排序; 11: 完成攻擊、Retaliation、傷害與死亡的戰鬥縱切; 12: 以 Arthur 與 Bulwark Sword 建立中央衍生特徵求值器.

**Status:** completed

- [x] Activated ability 在 Opportunity 宣告時固定合法 mode／target、計算並支付 cost，建立包含 source LKI 與 controller 的 Ability Instance 後入 Effects Stack。
- [x] Triggered ability 從 committed Event Batch 收集；choose-one 在入 Stack 時固定，depending-on 在結算時計算，來源離場後仍可透過 LKI 結算。
- [x] Typed operations 至少支援選擇、zone move、draw、counter、damage 與 continuous modifier，所有結果皆產生可重播的 committed events。
- [x] Pending Choice 保存 continuation，僅以 actor 可見的 View Handle 呈現選項；取消、無合法選項與失效來源不留下部分結果。
- [x] Ability usage 以 Ability Instance identity 追蹤；Object 離場再進場後不繼承 once-per-instance 狀態。
- [x] Instanced 與 static continuous effect 分別支援 snapshot target 與動態 predicate，並由中央 evaluator 依 duration、layer 與 timestamp 求值。

## 完成紀錄

- 2026-09-13：Action 與 Impact Hammer trigger 已遷移為同一種 `Ability Instance` stack payload；instance 保留 controller、source LKI、target 與 operation sequence。
- typed operation 已實作 choose continuation、move-to-graveyard、draw、counter、damage、continuous modifier；各操作透過 canonical game state 與 public event 保留可重播結果。
- choice continuation 只產生 actor 的 View Handle；完成選擇後建立新的 stack item，因此 source LKI 與 once-per-instance identity 不依賴 Field object。
