# 12.5: 建立統一 Ability 與 Effect Runtime

**What to build:** 建立固定 Support Set 可共用的 activated／triggered ability 執行核心：以 Ability Instance、typed operation、統一 Effects Stack item、可重播 Pending Choice 與 continuous effect lifecycle 處理能力的宣告、付款、結算與事件。

**Blocked by:** 10: 以 Impact Hammer 完成觸發收集與排序; 11: 完成攻擊、Retaliation、傷害與死亡的戰鬥縱切; 12: 以 Arthur 與 Bulwark Sword 建立中央衍生特徵求值器.

**Status:** ready-for-agent

- [ ] Activated ability 在 Opportunity 宣告時固定合法 mode／target、計算並支付 cost，建立包含 source LKI 與 controller 的 Ability Instance 後入 Effects Stack。
- [ ] Triggered ability 從 committed Event Batch 收集；choose-one 在入 Stack 時固定，depending-on 在結算時計算，來源離場後仍可透過 LKI 結算。
- [ ] Typed operations 至少支援選擇、zone move、draw、counter、damage 與 continuous modifier，所有結果皆產生可重播的 committed events。
- [ ] Pending Choice 保存 continuation，僅以 actor 可見的 View Handle 呈現選項；取消、無合法選項與失效來源不留下部分結果。
- [ ] Ability usage 以 Ability Instance identity 追蹤；Object 離場再進場後不繼承 once-per-instance 狀態。
- [ ] Instanced 與 static continuous effect 分別支援 snapshot target 與動態 predicate，並由中央 evaluator 依 duration、layer 與 timestamp 求值。
