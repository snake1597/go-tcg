# 每個引擎版本鎖定規則快照

首版規則引擎以 `rules` 儲存庫的 commit `602c917f2f8fd4df7198429a72eb596bf7f647c6`（2026-08-24）為規格基準，不在執行時或建置時自動追蹤最新規則。官方規則變動必須透過明確的引擎版本升級導入，並先更新相應的規則測試；日後選定固定牌組時，卡面資料也必須另行鎖定版本，以維持測試與重播結果可重現。

固定牌組的卡面資料選定 repository 內的 `./card/*.json` 為唯一來源，並由根目錄 `card-data-manifest.json` 的 data version、逐檔 SHA-256 與資料集 SHA-256 固定；目前選用的具體版本只在 [`card.md`](../card.md) 登錄。引擎不在執行或建置期間自動抓取外部卡面。

## 曾考慮的方案

永遠使用最新官方規則可減少人工升版工作，但同一版引擎的行為可能在未修改程式碼時改變，使歷史測試與重播失去可信度。
