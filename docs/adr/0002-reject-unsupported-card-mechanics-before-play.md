# 在開始單局前拒絕未支援的卡牌機制

初期產品僅支援明確列出的內容閉包，不默默近似完整遊戲。每份固定牌組 manifest 必須同時列出 Main Deck、Material Deck 與 `Outside Game Pool`；引擎由此遞迴建立 `Support Set`，涵蓋所有可能實際建立或執行的 token、生成卡、Mastery、Status、雙面卡面及其他衍生內容。單局開始前，驗證會拒絕任何尚未完整支援其規則行為、必要機制或可達內容的牌組，並列出缺少項目；允許從無界卡池任意生成的效果在沒有封閉 allowlist 時視為未支援。單純指定卡名而不建立或執行該卡行為，只要求完整卡名索引，不要求支援其行為。

## 曾考慮的方案

只驗證牌組內卡牌，或接受含有部分效果／無效果實作的任意卡牌，可以讓更多牌組成功載入，但 token、Generate 與其他遊戲外內容仍可能在執行途中突破支援範圍，完成的單局也無法被信任為正確呈現卡面規則。
